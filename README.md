# Bitcoin Ransomware Analysis

## 📌 Project Overview

This project explores the **BitcoinHeist Ransomware Address Dataset** to identify patterns and characteristics associated with Bitcoin addresses linked to ransomware activities.

The project focuses on Exploratory Data Analysis (EDA), data quality assessment, statistical analysis, and data visualization to better understand the dataset and prepare it for future machine learning classification tasks.

## 🎯 Objectives

- Explore and understand the dataset structure and features.
- Analyze class distribution and address class imbalance.
- Investigate data quality, correlations, and outliers.
- Visualize patterns and relationships between variables.
- Prepare the data for future machine learning classification models.

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter lab

## 📊 Dataset

**Source:** [UCI Machine Learning Repository — BitcoinHeist Ransomware Address Dataset](https://archive.ics.uci.edu/dataset/526/bitcoinheistransomwareaddressdataset)

The dataset contains Bitcoin transaction-related features and labels identifying addresses associated with ransomware categories or classified as `white`.

## 🚀 Project Status

The project currently focuses on exploratory data analysis and data preparation. Machine learning model development and evaluation are planned for future stages.

## ⚠️ Disclaimer

Dataset labels are not independent proof of criminal activity. The analysis is intended for educational and research purposes.
